# Bam Restaurant Website A modern, elegant, and fully responsive restaurant website built with **HTML5**, **CSS3**, **Bootstrap 5**.

![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3-purple)
![Responsive](https://img.shields.io/badge/Responsive-Yes-success)

## Overview
Bam Restaurant is a responsive restaurant landing page designed to showcase authentic Afghan cuisine, professional chefs, restaurant information, and online table reservations.
The project focuses on clean UI design, user-friendly navigation, and mobile responsiveness.

## Features
* ✅ Responsive Navigation Bar
* ✅ Attractive Hero Section
* ✅ About Restaurant Section
* ✅ Food Menu Showcase
* ✅ Professional Chef Team
* ✅ Online Reservation Form
* ✅ Contact Information
* ✅ Footer with Quick Links
* ✅ Mobile-Friendly Design
* ✅ Bootstrap Icons Support

